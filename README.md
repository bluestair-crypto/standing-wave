# 정상파 실험실

고등학교 물리학 수업용 한국어 정상파 웹앱입니다. 서버, 로그인, 설치, 외부 라이브러리 없이 동작합니다.

## 실행

`index.html`, `styles.css`, `app.js`를 같은 폴더에 두고 `index.html`을 브라우저에서 여세요. 인터넷 없이도 실행됩니다.

## GitHub Pages 배포

1. GitHub 저장소를 만들고 위 세 파일을 저장소 최상위 폴더에 업로드합니다.
2. 저장소의 **Settings → Pages**를 엽니다.
3. **Build and deployment → Source → Deploy from a branch**를 선택합니다.
4. **main** 브랜치와 **/ (root)** 폴더를 선택하고 저장합니다.
5. 배포가 완료되면 Pages에 표시되는 주소로 접속합니다.

빌드 명령이나 패키지 설치는 필요하지 않습니다. 파일명 대소문자와 상대 경로를 유지하세요.

## 조작

- 탭에서 줄, 열린 관, 한쪽이 닫힌 관을 선택합니다.
- 진동 모드, 재생/일시정지, 0.25·0.5·1배 속도, 마디·배 표시, 수식 표시를 조작합니다.
- 초기화하면 첫 번째 탭의 기본 진동, 재생 중, 1배 속도, 모든 표시 ON으로 돌아갑니다.
- 탭은 좌우 방향키와 Home/End 키로도 선택할 수 있습니다.
- 두 관에서는 `공기 입자 보기(종파)`와 `파형으로 보기`를 전환할 수 있습니다. 기본값은 공기 입자 보기입니다. 각 관의 보기 선택은 탭을 이동해도 유지되며 초기화하면 공기 입자 보기로 돌아갑니다.
- 파형 보기는 같은 변위 함수를 세로 방향으로 확대해서 그린 그래프입니다. 두 표현의 마디·배와 시간 위상은 같으며, 보기를 전환해도 시간·모드·재생 상태·속도는 바뀌지 않습니다. 실제 공기 입자의 운동 방향은 관의 길이 방향입니다.

## 물리 모델

x는 매질의 평형 위치, L은 줄이나 관의 길이입니다. 위치에 따른 진폭과 시간에 따른 진동을 곱하므로 파형을 좌우로 이동시키지 않습니다.

- 줄: y(x,t) = A sin(nπx/L) cos(nω₁t), n = 1,2,3,4. 양 끝 마디, 배 n개.
- 열린 관: ξ(x,t) = A cos(nπx/L) cos(nω₁t), n = 1,2,3,4. 양 끝 변위의 배.
- 닫힌 관: ξ(x,t) = A sin(mπx/(2L)) cos(mω₁t), m = 1,3,5,7. 왼쪽 변위 마디, 오른쪽 변위 배.

관의 입자는 평형 위치 x에서 ξ만큼 좌우로 움직입니다. 마디·배의 표시는 평형 위치에 고정됩니다. 금색 점은 배의 움직임을 강조합니다. 입자 간격 변화는 종방향 운동에 따르는 결과이며, 압력 크기를 색으로 표현하지 않습니다. 열린 끝 입자는 경계를 넘어 움직일 수 있습니다.

두 관의 두 표현은 `pipeDisplacement()` 하나를 공유합니다. 매 프레임 고정된 평형 좌표에서 공간 함수 × 시간 함수를 계산하며, 이전 프레임의 입자 위치를 누적하거나 공간 위상을 이동하지 않습니다. 마디와 배의 정확한 좌표를 그리기에 포함하고 마디의 부동소수점 오차는 0으로 처리합니다.

`verifyPipeStandingWaves()`는 앱 시작 시 모든 관 모드에 대해 한 주기의 33개 시각에서 마디의 변위 0, 고정된 배의 최대 진폭, 양 끝 경계 조건, 위치별 진폭 범위, 반대 방향 두 파동의 중첩과의 수치적 일치를 검사합니다. 검증용 중첩 식은 애니메이션 계산에 사용하지 않습니다.

각 모형의 기본 진동은 관찰용으로 초당 0.32회로 느리게 표현하며 배진동은 같은 모형 안에서 정수배 진동수를 유지합니다. 서로 다른 관의 실제 기본 진동수를 비교하는 모형은 아닙니다. 이상적인 경계 조건을 사용하며 열린 관의 끝 보정은 생략합니다.

줄의 옅은 두 곡선은 순간 변위가 도달할 수 있는 ±A sin(nπx/L) 경계입니다. 일시정지 상태에서도 모드를 변경해 공간적인 모양을 비교할 수 있습니다.
